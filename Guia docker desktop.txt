========================================================================
GUIA DE SOLUCION: ERROR DE VIRTUALIZACION EN DOCKER DESKTOP (WINDOWS)
========================================================================

Este documento detalla los pasos tecnicos necesarios para resolver el error:
"Virtualization support not detected / Docker Desktop failed to start".

La resolucion consta de tres fases consecutivas: Diagnostico, Habilitacion en Hardware (BIOS/UEFI) y Activacion en Software (Windows).

------------------------------------------------------------------------
FASE 1: DIAGNOSTICO DE ESTADO
------------------------------------------------------------------------
Proposito: Determinar si la virtualizacion esta bloqueada por hardware o si falta configurar el sistema operativo.

Pasos:
1. Abra el Administrador de tareas (Presione Ctrl + Shift + Esc).
2. Seleccione la pestana "Rendimiento" y luego haga clic en "CPU".
3. Observe la etiqueta "Virtualizacion" en la esquina inferior derecha:
   - Si figura como "Deshabilitado": Realice la Fase 2 y luego la Fase 3.
   - Si figura como "Habilitado": Realice unicamente la Fase 3.

------------------------------------------------------------------------
FASE 2: HABILITACION EN HARDWARE (BIOS/UEFI)
------------------------------------------------------------------------
Proposito: Activar la capacidad fisica de virtualizacion de la CPU en la placa madre.

Pasos:
1. Reinicie la computadora.
2. Presione la tecla correspondiente para ingresar al menu de configuracion de la BIOS/UEFI durante el arranque. Dependiendo del fabricante, la tecla suele ser: Del (Suprimir), F2, F10 o F12.
3. Navegue hasta la seccion de configuracion del procesador. Puede figurar como: "Advanced", "CPU Configuration", "Processor Settings" o "Overclocking".
4. Localice la opcion de virtualizacion y cambie su estado a "Enabled" (Habilitado). Segun su procesador, buscara:
   - Procesadores Intel: "Intel Virtualization Technology", "Intel VT-x" o "VT-d".
   - Procesadores AMD: "SVM Mode" (Secure Virtual Machine) o "AMD-V".
5. Presione F10 para guardar los cambios y salir. La computadora se reiniciara de forma habitual.

------------------------------------------------------------------------
FASE 3: ACTIVACION EN SOFTWARE (CARACTERISTICAS DE WINDOWS)
------------------------------------------------------------------------
Proposito: Habilitar los componentes de virtualizacion del sistema operativo (Hypervisor y WSL2) necesarios para que Docker funcione.

Pasos:
1. En la barra de busqueda de Windows, escriba "Activar o desactivar las caracteristicas de Windows" y presione Enter.
2. En la lista desplegable, marque las siguientes casillas:
   - Plataforma de maquina virtual
   - Subsistema de Windows para Linux (WSL)
   - Hyper-V (Esta casilla solo estara disponible en ediciones Windows Pro y Enterprise. Si utiliza Windows Home, ignore este paso).
3. Haga clic en Aceptar. Windows descargara e instalara los archivos de soporte.
4. Reinicie el equipo cuando el sistema lo solicite.
5. Abra PowerShell como Administrador y ejecute el siguiente comando para actualizar el nucleo de WSL a la ultima version estable:
   wsl --update
6. Ejecute el siguiente comando para aplicar la actualizacion:
   wsl --shutdown

------------------------------------------------------------------------
COMPROBACION FINAL
------------------------------------------------------------------------
Una vez completadas las fases:
1. Inicie Docker Desktop.
2. El motor de Docker se ejecutara en segundo plano y el icono de la bandeja de sistema cambiara a color verde (indica estado "Running").
