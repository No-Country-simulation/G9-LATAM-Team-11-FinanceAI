========================================================================
📂 SERVICIO: backend (API REST en Java Spring Boot)
========================================================================

¿QUÉ ES ESTA CARPETA?
Contiene el código fuente del servidor de la aplicación (el Backend),
desarrollado en Java 17 y Spring Boot.

¿PARA QUÉ SIRVE?
Orquesta todo el sistema: recibe las peticiones del Frontend, consulta la
base de datos PostgreSQL, lee los modelos de IA de 'shared-models/' y
devuelve las respuestas estructuradas al cliente.

ROLES INVOLUCRADOS Y CÓMO USARLA:

⚙️ BACKEND DEVELOPER:
- Escribe el código de Java aquí (controladores, servicios, repositorios).
- El contenedor de Docker mapea esta carpeta, lo que significa que el servidor
  se compilará y ejecutará de forma automática al levantar Docker.
- Conéctate a la base de datos PostgreSQL localmente usando el puerto '5433'
  (credenciales en docker-compose.yml).

🎨 FRONTEND DEVELOPER:
- Consume los endpoints expuestos por este servicio en 'http://localhost:8081'.
- Lee los archivos de ayuda de endpoints o el pom.xml para entender la estructura.

⚠️ REGLA DE ORO DEL EQUIPO:
Para producción y despliegue final en OCI, crearemos un Dockerfile Multi-stage
dentro de esta carpeta para empaquetar el código compilado (.jar) junto con los
modelos ONNX en una imagen ultra-segura.
